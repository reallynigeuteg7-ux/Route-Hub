Как открыть сайт:
1. Открой файл index.html двойным кликом.
2. Все абонементы сохраняются в браузере на этом ноутбуке.
3. Чтобы не потерять данные, периодически жми "Экспорт JSON".
4. Если надо перенести данные на другой ноут, открой сайт там и нажми "Импорт JSON".
5. Для импорта из Excel нажми "Импорт Excel" и выбери файл .xlsx или .xls.

Что умеет сайт:
- добавлять новый абонемент
- редактировать запись
- удалять запись
- списывать 1 посещение
- быстро продлевать абонемент на 30 дней
- искать по имени
- фильтровать по статусу
- импортировать Excel

Какой Excel подходит:
Нужны столбцы:
- Имя Фамилия
- Дата от
- Дата до
- Осталось посещений
- Всего посещений
- Комментарий

В архиве уже лежит пример файла: abonements-sample.xlsx

Важно:
- Это локальный сайт без сервера и без базы данных.
- Данные хранятся через localStorage текущего браузера.
- Если очистить данные браузера, записи могут исчезнуть.
- Поэтому экспорт JSON лучше делать регулярно.
- Импорт Excel работает через библиотеку SheetJS из CDN. Если кнопка не работает, просто открой сайт при включенном интернете.
