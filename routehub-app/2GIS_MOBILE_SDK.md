# 2GIS Mobile SDK

## Что это

`2GIS Mobile SDK` нужен для нативной карты и встроенной навигации внутри приложения.

Текущий вариант в проекте:

- карта и маршрут работают через `Routing API + WebView`
- встроенной поездки внутри приложения пока нет

Для полноценного режима `В путь` внутри приложения нужен именно `Mobile SDK Full`.

## Наш App ID

Текущий идентификатор приложения:

- iOS: `com.routehub.app`
- Android: `com.routehub.app`

Именно этот `App ID` был нужен 2GIS для выпуска `dgissdk.key`.

## Полученные key files

Файлы ключей сохранены локально:

- Android: `native-keys/2gis/android/dgissdk.key`
- iOS: `native-keys/2gis/ios/dgissdk.key`

Важно: эти файлы нельзя отправлять в публичный репозиторий. Папка `native-keys/` добавлена в `.gitignore`.

## Что будем делать дальше

План интеграции:

1. Перевести Expo-проект в режим с нативными папками через `expo prebuild`.
2. Подключить 2GIS Mobile SDK в `android` и `ios`.
3. Привязать нужный `dgissdk.key` к каждой платформе.
4. Сделать отдельный нативный экран карты.
5. Подключить встроенную навигацию и кнопку `В путь`.

## Важно про Expo

Expo не мешает публикации в `App Store` и `Google Play`.

Но для `2GIS Mobile SDK` нужен нативный слой, поэтому одного `WebView` недостаточно.

Это не новый проект с нуля. Это тот же проект, но с добавлением `android/` и `ios/` через `expo prebuild`.
